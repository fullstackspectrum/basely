How Basely compares

Each image's package database is read straight from its layers over the registry API, for {{PLATFORM}}, and every package is looked up in OSV against its distro's own advisory feed, so backported fixes count as fixed. Advisories the distro marks as unimportant or negligible, Chainguard false positives and kernel advisories (a container runs on the host's kernel) are left out.

Images are ranked by severity-weighted advisories, then size. A candidate that would break a stage, such as one with no shell under a stage with RUN steps, is never the recommendation; it can be offered as worth the changes when it at least halves the risk. Counts cover OS packages only, not what your build installs on top.
